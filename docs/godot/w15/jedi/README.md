# Named Jedi library

The seven stable IDs are `kira`, `tor`, `satele`, `ressa`, `kell`, `sava`, and `tem`. `godot/assets/characters/jedi/manifest.json` contains each display name, files, geometry measurements, saber color, exact Meshy prompts and task IDs, and credit cost. Each folder contains an animated `id.glb`, a 1,400-triangle static `id_lod.glb`, and a front / three-quarter preview PNG. The main GLB has 3,000 triangles and the ten clips battle uses: `idle`, `saberIdle`, `run`, `walk`, `swing`, `cast`, `shoot`, `hit`, `death`, `block`. The bone names match the shared unit skeleton, including `pelvis` and `hand_r`.

For battle, call `preload("res://scripts/characters/jedi_models.gd").scene_for(unit, generic_scene)`. For an ID, call `scene_for_id("kira", generic_scene)`. The existing `combat_scene.gd` model-selection call already uses the named lookup. Unknown names and missing GLBs return the generic Jedi scene. The explicit Low LOD file is static; battle relies on Godot's generated mesh LODs on the animated main scene.

For other scenes, read the manifest by ID and load `res://assets/characters/jedi/<id>/<id>.glb` as a `PackedScene`. Match roster display names through `jedi_models.gd` or persist the stable ID. Armory integration should change the model choice in `campaign/loadout_actor.gd` during the Wave 15 integrate step; that file is leased to the armory lane now. Portraits and story scenes can use the same scene and the `idle` clip.

To refine one character, use its selected `mesh_task_ids.preview` with the saved `prompts.texture` for a new Meshy refine task, or its selected refine ID for another rig task. Regenerate only if the geometry brief changes. `CREDITS.md` records every paid task and the rejected rig request. The Meshy rigs were checked with `tools/meshy/retarget.mjs`. Its baked bone tracks folded the imported skin in Godot, so the library uses the ten gameplay clip names with compact skeletal motion authored on the Meshy skeleton. The original Quaternius motion curves are not shipped in these GLBs. The static Low LOD can be used for distant stills; the main scene's generated mesh LODs serve animated battle.
