Meshy models: our UAL clips are baked onto each rig offline (world-space retarget with rest-pose alignment; fingers keep the model's rest pose), bones renamed to the UAL names the game attaches gear to, a `grip_r` node added for weapons, textures cut to one 1024 px WebP base color, meshes quantized and meshopt-compressed (~12 MB → ~1.4 MB each). Code: `public/js/view3d/figures.js` (`UNITS` lists which kinds use them; a missing file falls back to the mannequin). `units/acolyte.glb` is benched (Meshy's auto-rig misread the robed legs). Props: remeshed on Meshy or simplified to ~3–9K tris, 512 px WebP base color (`tools/meshy/prop.mjs`); `public/js/view3d/props.js` (`PROPS`) swaps them in for the primitive tiles and scenery.

Changes made for this game (allowed by CC0): animations trimmed to the clips we use and renamed, scale tracks dropped, keyframes resampled, geometry quantized and meshopt-compressed (21 MB → 1.2 MB). Robes, armor, helmets, sabers and blasters are low-poly parts built in code (`public/js/view3d/figures.js`) and attached to bones; terrain, scenery and effects are also built in code (`board.js`, `themes.js`, `effects.js`).

Total 3D download: ~1.5 MB models + ~0.85 MB scripts, loaded only when the 3D view opens a mission (beast model only when a mission has a creature).

Only CC0 or other permissive licenses go in this folder, each listed here with author, link and license.
