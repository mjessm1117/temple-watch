# Loadout assets

- `models/jedi.glb`, `trooper.glb`, `scout.glb`: copies of the existing Godot unit assets, originally generated by Jess with Meshy 6 under his paid private license. See `public/models/CREDITS.md` and `godot/assets/models/CREDITS.md`.
- `models/medic.glb`, `heavy.glb`: existing `public/models/units/` assets by Jess, same license. Decoded with the locally cached glTF Transform 4.5.1 `dequantize` command for Godot import. Geometry, textures, rigging and animation retained.
- Embedded animation clips: Quaternius Universal Animation Library, CC0; https://quaternius.com/packs/universalanimationlibrary.html. Existing project retargets retained.
- `icons/*.svg`: existing Temple Watch stroke paths copied from `public/js/icons.js`, with explicit SVG stroke styling for Godot. No external download.
- Hangar geometry, equipment attachments and synthesized audio are built in the loadout scripts. No new third-party assets.
